# ASP Assessoria

Landing page da ASP Assessoria — assessoria especializada em compras corporativas (materiais de escritório, TI, embalagens, logística, mobiliário, máquinas, comunicação visual e soluções digitais).

Página estática, sem dependências de build — abra `index.html` diretamente ou publique via GitHub Pages.

## Stack

- HTML, CSS e JavaScript puros (sem frameworks)
- Fontes: Sora, Inter e Manrope (Google Fonts)
- Logos de parceiros embutidas como imagens locais

## Publicar com GitHub Pages

Em **Settings → Pages**, selecione a branch `main` e a pasta raiz (`/`). O site ficará disponível em `https://arthursouzadeveloper.github.io/ASPAssessoria/`.
